# Font Sleuth 1.0

Finds the **font, weight, size and colour** of text in a picture (PNG, JPG, BMP, GIF, TIFF, WebP) or a PDF.

## How to use it

1. **Open** a picture or PDF (Ctrl+O, or drop the file on the window).
2. **Drag a box** around *one line* of text. (Already-cropped snippet? Use *Select whole picture*, Ctrl+A.)
3. **Type** the words you see. Not needed for PDFs that contain real text.
4. Press **Analyze** (Ctrl+Enter). The answer appears on the right, with the next-best alternatives and a
   "Compare by eye" picture: your text next to the chosen font redrawn at the estimated size and colour.

## What is exact and what is estimated

| Input | Result | How |
|---|---|---|
| PDF with real (selectable) text | **Exact** font name, weight, size (pt) and colour | Read from the PDF's text data |
| Picture, or PDF page that is itself a picture / scan | **Estimated** | The typed text is drawn in every installed font and compared with your pixels; colour is fitted against the best match |

Things worth knowing:

* A picture can only be matched to fonts **installed on this computer**. If the real font is missing you get the
  closest look-alike and a warning. Use **Fonts > Add font folder** to include more fonts.
* Point sizes depend on the picture's resolution (DPI). The file's own value is used when it has one; screenshots are
  usually 96 DPI. The font and pixel size do not depend on it.
* Fonts with near-identical shapes (for example Arial and Liberation Sans) cannot be told apart from pixels. When
  the top two results are nearly tied the app says so instead of picking silently.
* Accuracy drops for very small text (under ~14 px tall), heavy JPEG compression, and letter-spaced headings.
  Weight and colour are the first things to become uncertain; the app warns when that applies.
* Invisible OCR text hidden in scanned PDFs is ignored, because it does not describe what is visible.

## Running

Needs Python 3.12 or newer.

```bash
pip install -r requirements.txt
python run_fontsleuth.py            # or: python -m fontsleuth  (from the src folder)
```

Windows `.exe`: double-click `build_exe.bat`. It creates a virtual environment, installs the requirements and
PyInstaller, and writes `dist\FontSleuth.exe`.

Settings are stored per user (QSettings). The log file, the font cache and error details are in the user's
application-data folder; *Help > Open log folder* opens it. Typed text and file contents are never logged.

## Project layout and conventions

* `src/fontsleuth/` - the program. Logic modules have no Qt imports; GUI modules are `canvas`, `control_panel`,
  `result_panel`, `main_window`, `app`, plus `background` (worker threads).
* `tests/` - `pytest` + `pytest-qt` (`pip install -r requirements-dev.txt`, then `python -m pytest`).
* `docs/note-index.md` - index of every class and method note number, generated by `python tools/notes.py`.
  Write new docstrings with `#?` as the number and `[[Class.method]]` for cross-references, then run the tool: it
  assigns the next numbers and fills in the reference numbers. `python tools/notes.py --check` verifies everything
  (it is also part of the test suite).
* `tools/make_single_file.py` - builds the single-file edition. `tools/make_release.py` builds the release zip.
